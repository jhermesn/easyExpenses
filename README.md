## Easy Expenses

Aplicativo PWA para controle de finanças pessoais, com foco em simplicidade, uso offline e relatórios visuais. Organize entradas e saídas por categorias (com regras de porcentagem), acompanhe fluxo semanal, gere relatórios em PDF e mantenha seus dados localmente no dispositivo.
