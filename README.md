## Easy Expenses

Aplicativo PWA open-source para controle de finanças pessoais, com foco em simplicidade, uso offline para maior privacidade e relatórios visuais. Organize entradas e saídas por categorias (com regras de porcentagem), acompanhe fluxo semanal, gere relatórios em PDF e mantenha seus dados localmente no dispositivo.

Você pode contribuir com o projeto para melhorá-lo para todos. Mande sua Pull Request.
